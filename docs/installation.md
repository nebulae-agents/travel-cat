# Travel Cat 安装与使用

## 当前候选范围

新候选包包含一个 `Travel Cat.app` 与说明/许可文件。默认黑猫、相册界面和必要辅助程序都在应用内；不需要外置插件或将默认宠物复制到 Codex 目录。自有窗口、右键菜单和跟随纸条不依赖 Codex 桌面窗口。

生产内置调度、通用 Runtime 与 ACP 切换尚未完成。桌面可用不等于正式自动旅行与生成已迁移；当前不要自动停用旧 heartbeat 或据此覆盖生产安装。

## 安装边界

当前候选采用 ad-hoc 临时签名，尚未 Apple 公证，仅供受控验证。不要关闭 Gatekeeper、移除 quarantine 或重置输入监控权限。系统拒绝打开或签名验证失败时应停止，不绕过安全保护。

新安装通常使用当前用户的 Applications 或系统 /Applications，两处不要保留同标识的重复有效安装。已有安装必须先核对实际应用路径、相册路径、备份与旧调度，再进行经确认的迁移。本轮不会自动替换应用、移动相册、修改 Codex 宠物或删除插件。

源码中的 `Deploy Local.command` 已改为只安装应用：从干净、已提交源码构建，备份旧应用后替换，失败时尝试恢复。新收据为 v2，仅记录应用；旧 v1 收据仍校验并原样备份，未完成恢复的旧记录不会被跳过。新配置向导只询问应用目录和相册目录；旧配置可原样复用，重新生成时保存精确备份再升级。不要删除旧配置备份，迁移旧安装记录时可能需要它核对绑定。此变更仅完成隔离测试，不代表已更新本机安装；详见[本地部署说明](local-deployment.md)。

## 桌面与测试

- 首次启动显示自有小猫；已手动隐藏时重启保持隐藏。从菜单栏爪印选择“显示桌面小猫”恢复。
- 右键小猫可打开状态、最新明信片、旅行册和设置。在家显示黑猫，准备时带行李，外出及返程途中显示空屋。
- 猫爪提示随屋子或黑猫按相对位置移动。单独拖动猫爪提示可调整偏移，松手后记住位置；提示展开或收起时保持中心位置。拖动不会打开提示内容，普通点击仍可查看。屏幕断开时会将不可触达的提示移回可见屏幕，不覆盖记住的偏移。
- 默认黑猫回家后会轮换眨眼、抬爪、歪头等动作，完整播放一个动作后再切换，不连续重复。隐藏桌面宠物或开启系统“减少动态效果”时停止动画；自定义角色保留原有动作规则。
- 快速测试中的紧凑旅程使用固定内容，仅写入独立测试区域，不消耗模型额度。真实生成测试另行消耗已配置 CLI 的额度，不能等同于正式内置调度。
- 自定义宠物沿用既有角色导入与冻结规则；无参考图时跨图一致性有限，不自动替换成默认黑猫。

## 旧工作流兼容说明

既有插件和每 15 分钟 heartbeat 不会自动改变；无工作时的 `NO_REPLY`、图片优先与一次一个动作规则仍属于旧工作流。候选包不附带新插件，也不要求新建自动化。切换生产调度前需另行确认并防止双执行者。

兼容命令返回的 `runtime.dataRoot` 标识实际数据根；不要把开发目录或另一个安装的数据根当作当前相册。已有明信片、角色、设置与备份不得因卸载、隐藏或暂停而删除。
