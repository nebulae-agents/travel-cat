# Travel Cat 安装与使用

## 当前候选范围

新候选包包含一个 `Travel Cat.app` 与说明/许可文件。默认黑猫、相册界面和必要辅助程序都在应用内；不需要外置插件或将默认宠物复制到 Codex 目录。自有窗口、右键菜单和跟随纸条不依赖 Codex 桌面窗口。

2026-10-28 已按授权合并 #7–#9、#30–#33，安装公开主干 `a17b88750548d639b122c6a8523c92db126c7e68` 的 1.4.1/build 42，并核对源码标识、签名、收据、旧版备份和实际运行文件。正式工作台、最小窗口及备份验收已完成；自动旅行仍报告生成失败，真实生成成功尚未通过本轮验收。准确版本、已验收范围与缺口见[交付状态](delivery-status.md)。

默认黑猫的应用内自动旅行和图片任务调度已实现；需在「模型与连接」配置文本与图片服务，并开启「自动旅行」。自定义角色的自动旅行暂未启用。Agent 工作台已有 Native/ACP 实现，ACP 的 SSH/Docker 实机不在已完成的本机验收范围内。实际提供方、多趟运行和旧 heartbeat 的当前启停状态未核实，不能据此宣称迁移已全部完成或双调度已消除。

## 安装边界

当前候选采用 ad-hoc 临时签名，尚未 Apple 公证，仅供受控验证。不要关闭 Gatekeeper、移除 quarantine 或重置输入监控权限。系统拒绝打开或签名验证失败时应停止，不绕过安全保护。

新安装通常使用当前用户的 Applications 或系统 /Applications，两处不要保留同标识的重复有效安装。已有安装必须先核对实际应用路径、相册路径、备份与旧调度，再进行经确认的迁移。普通解压与源码发布不会自动替换应用、移动相册、修改 Codex 宠物或删除插件；本机更新是另行授权的部署操作。

源码中的 `Deploy Local.command` 已改为只安装应用：从干净、已提交源码构建，备份旧应用后替换，失败时尝试恢复。新收据为 v2，仅记录应用；旧 v1 收据仍校验并原样备份，未完成恢复的旧记录不会被跳过。新配置向导只询问应用目录和相册目录；旧配置可原样复用，重新生成时保存精确备份再升级。不要删除旧配置备份，迁移旧安装记录时可能需要它核对绑定。部署事务已有隔离测试，当前 build 42 的本机更新另已完成源码、签名及正式工作台与备份核对；这不代表所有提供方、账户或完整旅程均已验收。操作契约见[本地部署说明](local-deployment.md)，时点证据见[交付状态](delivery-status.md)。

## 桌面与测试

- 首次启动显示自有小猫；已手动隐藏时重启保持隐藏。从菜单栏爪印选择“显示桌面小猫”恢复。
- 右键小猫可打开状态、最新明信片、旅行册和设置。在家显示黑猫，准备时带行李，外出及返程途中显示空屋。
- 猫爪提示随屋子或黑猫按相对位置移动。单独拖动猫爪提示可调整偏移，松手后记住位置；提示展开或收起时保持中心位置。拖动不会打开提示内容，普通点击仍可查看。屏幕断开时会将不可触达的提示移回可见屏幕，不覆盖记住的偏移。
- 默认黑猫回家后会轮换眨眼、抬爪、歪头等动作，完整播放一个动作后再切换，不连续重复。隐藏桌面宠物或开启系统“减少动态效果”时停止动画；自定义角色保留原有动作规则。
- 快速测试中的紧凑旅程使用固定内容，仅写入独立测试区域，不消耗模型额度。真实生成测试另行消耗已配置 CLI 的额度，与内置调度的真实长期运行分别验收。
- 自定义宠物沿用既有角色导入与冻结规则；无参考图时跨图一致性有限，不自动替换成默认黑猫。

## 旧工作流兼容说明

兼容源码保留旧插件和每 15 分钟 heartbeat 的工作流约定：无工作时 `NO_REPLY`、图片优先、一次一个动作。候选包不附带新插件，也不要求新建自动化；本次交付未核实旧 heartbeat 的实时启停或完成迁移。切换生产调度前需核对实际执行者并防止重复调度。

兼容命令返回的 `runtime.dataRoot` 标识实际数据根；不要把开发目录或另一个安装的数据根当作当前相册。已有明信片、角色、设置与备份不得因卸载、隐藏或暂停而删除。
