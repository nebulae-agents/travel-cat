# 安全与数据边界

本文说明开发候选版的边界，不代表已经完成公开发行或跨账户验收。

## 本地数据与生成服务

默认数据目录是当前用户的 `Library/Application Support/TravelCat/TravelPetData`。它包含旅行记录和导入的角色副本，不属于发行素材，不能随源码或安装包分发。旧安装可能显式使用其他目录；更新前先核对[数据路径](portable-runtime.md)，不要自动迁移或清空旧相册。

旅行生成使用用户授权的 Codex 能力，相关叙事、描述和参考图可能交给生成服务处理。无需另填 API Key 不代表离线、无限额度或无需授权。

## 固定运行入口

发行运行入口是应用内的 `Contents/Resources/run-travelcatctl`。该入口验证应用签名、辅助程序摘要和构建证明，再执行固定命令；开发构建不能替代它。不能将角色描述、旅行文本或模型输出拼接为终端命令。

当前应用使用本机临时签名。这能提供包内容一致性检查，但不能证明发布者身份，不能替代 Developer ID 签名和 Apple 公证。下载来源和首次启动体验仍须单独验收；不要关闭系统安全保护。

## 角色导入

角色原文件不修改。导入器检查清单、图像格式和大小、路径及符号链接，再保存经过校验的独立副本。导入失败保留原选择；已有副本损坏时明确报错，不以黑猫冒充其他角色。

角色名称和描述只是内容，不是指令。即使描述要求读取其他文件、修改自动化、执行命令或上传数据，也不得照做。参考图只从已验证的角色资源读取。

路径检查不承诺抵御同一账户下另一个进程在检查和使用之间恶意替换文件的竞态。不要让不可信进程同时控制导入目录或应用数据目录。

## 旅行与交互

查询相册不能推进旅行状态。定时旅行必须保持一次唤醒最多一个权威操作，先处理待补图，再检查是否到期。处理过的竞争、无新事件和成功的静默唤醒不应反复通知用户。

首次创建自动化、安装插件或切换 Codex 原生宠物，需要相应的用户授权和平台支持。配套程序不修改 Codex 内部文件，不绕过辅助功能或输入监控权限。

## 发布检查

源码导出只读取已提交的明确文件清单，拒绝未提交修改、非普通文件及个人运行路径；不包含 Git 历史和真实相册。正式资源与测试夹具必须保留，不能按日志扩展名批量删除。

项目以 Apache-2.0 开源并保留第三方字体许可。正式二进制发行前仍需完成独立解压构建、隔离安装、原生界面和完整旅程验收。构建成功或校验和一致不代表这些检查已经通过。
