# 可移植运行环境

本文描述默认数据位置、兼容与打包契约。2026-10-14 的公开主干、CI 和经授权的本机更新状态见[交付状态](delivery-status.md)；通用 Runtime 与 ACP 切换仍未完成。

## 新用户

默认发布包不包含作者个人目录。应用与随包的签名 CLI 使用当前用户的 `Library/Application Support/TravelCat/TravelPetData`。这份数据包含旅行记录，不应随源码提交或分发。

兼容插件必须调用随应用提供的 `Contents/Resources/run-travelcatctl`，不可调用开发构建。旧插件工作流使用 Codex 的生成能力，仍受用户额度、权限和运行条件限制。

独立应用的默认黑猫已有内置旅行与图片任务调度，并通过「模型与连接」分别配置文本和图片服务。可选择 Codex CLI 或 OpenAI-compatible 服务；后者可能需要 API 密钥，密钥保存在系统钥匙串。自定义角色自动旅行暂未启用，源码能力不等于真实提供方与长期运行已验收。

## 已有安装的兼容

如果旧应用通过 Info.plist 的 TravelCatDataRoot 使用非默认数据目录，新包必须显式保留这个目录后再替换旧应用。普通发布包不会自动搜索或迁移旧数据。

兼容打包形式：

```sh
Scripts/package-app.sh --data-root /absolute/existing/data-directory
```

此参数只将目录写入新包配置，不复制或修改该目录。包含个人目录的兼容包不可作为公共发行包；公开包使用无参数打包。安装前应核对新旧数据位置，不要用空相册来判断旧数据已丢失。

## 安全与发行限制

CLI 在执行固定命令前校验应用签名与辅助程序摘要。不要通过修改已签名应用内文件配置目录，修改会破坏签名；应重新打包。

当前打包脚本使用本机临时签名，不等于 Developer ID 签名或 Apple 公证。对外二进制发布必须单独验收系统首次启动提示，不能要求用户关闭系统安全保护。

默认源码导出与候选打包不替换现有安装，也不复制或迁移真实相册。2026-10-14 另经用户授权，通过部署入口完成了公开主干的本机更新；更新检查时，73 个正式数据文件、10 项相关只读偏好及数据位置保持不变。这是该次更新前后的对照结果，后续应用运行仍可能正常写入数据。旧 heartbeat 的实时状态和调度迁移未核实，本次交付未创建或替换生产旅行自动化。
