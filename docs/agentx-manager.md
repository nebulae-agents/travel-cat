## 两种入口

- **BlackCat 开启**：原桌宠原生保留，点击进入 AgentX 管理窗口；右键菜单保留旅程、明信片、旅行册、用品入口，并新增管理平台入口。
- **BlackCat 关闭**：设置中的“显示 BlackCat 桌宠”关闭后，其他应用继续运行。平台保持 Dock 身份，未读结果及旅行待处理提示汇总为数字；点击 Dock 打开管理窗口，有待处理时优先进入收件箱。
- 隐藏桌宠的偏好会保存，重启不再自动显示；菜单栏“显示黑猫与小屋”可重新开启。关闭管理窗口不退出进程。
- 单应用模式独立于桌宠开关：设置默认应用后，下次直接打开其前台，可返回完整平台。

## 当前源码范围（已安装 build 47）

### 配置到执行

1. **模型服务**：支持 OpenAI Compatible、Responses、Anthropic Messages。可获取模型清单、启用/收藏模型和设置分类默认；凭据 profile 只保存 Keychain 引用，多密钥顺序轮询。未实现自动 fallback 或真实费用预算。
2. **Agent 定义**：支持正文和 UTF-8 文件目录模式，保留 frontmatter、附属文件与未知字段；草稿、发布版本分离。实例可固定版本、设置变量和覆盖 profile。尚未接入的 runtime/tools/memory/limits 可保留草稿，发布执行会拒绝。
3. **应用和实例**：BlackCat、工作台与宿主文本应用各有入口；可编辑实例。未知应用类型保留配置，前台显示未接入，不错误地发送文本请求。
4. **统一引用**：旅行生成和工作台模型网关可引用平台服务及启用模型，运行时解析当前配置，不复制密钥。旅行图片仅接入 OpenAI Compatible 图片接口；原生 Codex 仍使用独立官方登录。
5. **前台与配置台**：前台使用窄导航栏，配置台展示应用成员、目录和版本入口。声明式应用包可提供受限表单前台，并保存本应用输入；不是任意 JS/Swift 插件加载器。
6. **运行与审计**：记录真实完成、失败、取消与未读状态；宿主文本运行的开始/结束/取消元数据进入加密哈希链。审计不可用时阻止请求，结束审计失败时保留响应并显示警告，不记录密钥或提示词原文。

切换应用不会改变结果归属。模型、实例变更保留引用校验；运行中不允许改绑。真实外部模型调用与账户授权须另行验收。

### 根目录、应用隔离与升级

- 默认 root 为 `~/Library/Application Support/AgentXManager`，定位及离线操作队列保存在外部 `AgentXHost`。设置页选择新的迁移目标，正常退出并确认子进程/daemon 停止后，下次启动复制、逐文件摘要校验并切换定位；原目录保留，失败不发布新定位。不是热迁移。
- `agentx.yaml` 仅保存平台设置；provider、profile、定义、应用、实例、运行按真实 YAML/JSON 分层存储。旧单文件格式保留原文备份；未知 YAML 字段随保存保留。
- BlackCat 数据位于 `apps/blackcat/state/travel`；工作台位于 `apps/workbench/state/runtime`。旧数据导入经过离线复制校验，源目录保留；旧外部 workspace 不自动继承权限，历史以只读形式呈现。旧实例重新授权向导仍待实现。
- 受控 workspace 和应用授权以 root 相对路径表达；SDK 文件 broker 使用描述符校验拒绝跨应用、链接和未授权共享。共享访问必须通过 `shared` 的显式授权。宿主 locator、迁移来源记录及机器上的可执行文件位置仍可能是绝对路径。
- 独立 `Packages/AgentXAppSDK` 提供 app manifest、数据 schema、host API、文件授权和升级契约。宿主接入代码包导入/导出、全状态备份、离线升级/回滚与恢复；跨 schema 需要宿主提供可信迁移。BlackCat 和原工作台的原生业务代码仍随宿主构建，尚非独立二进制插件。
- SDK deny-default 沙箱有真实受限子进程测试；不能将此证据等同所有框架均已完成沙箱验收。原生 Codex 和 Docker ACP 各自使用现有权限路径，真实登录、daemon、镜像与任务仍需单独验证。
- `AGENTX_ROOT` 用于隔离验收，默认使用同级独立 host 目录，也可指定 `AGENTX_HOST_DIRECTORY`；该模式跳过正式旅行/工作台历史导入。设置页使用注入的 host，不重新定位生产目录。
- 密钥仍在系统 Keychain，目录复制不会携带密钥。受管原生 Codex profile 在同机迁移时通过严格路径/进程校验复制其对应登录条目并读回，保留来源；这条路径目前只有替身测试，未执行真实登录凭据迁移。
