# 历史运行记录保存粒度优化验收

日期：2026-11-09。用户授权继续 P1 验收与优化，保留现有数据，不提交或推送。本变更在工作树中；正式客户端仍为 build 55，尚未安装本次优化。

## 原因与实现

`AgentXRepository.save` 原来把全部 `state.runs` 重新编码并加入事务，即使仅保存应用导航。JSON 键顺序或格式可改变，未识别的扩展字段也会丢失，所有历史文件修改时间都会刷新。

现在先通过原有安全路径检查，再解码既有运行记录，与内存 `AgentXRun` 全属性比较。相同记录不进入本次写入集合及回滚日志；新增或实际变化的记录继续使用原事务流程。既有文件损坏则在写入前报错，保留原文件，不能用内存状态悄悄覆盖。

这不是存储格式迁移，没有删除或搬动数据。配置文件仍沿用原保存策略；实际被编辑的运行记录仍会重新编码，其未知扩展字段保留不是本次承诺。比较仍需读取历史文件，尚未引入增量索引或跨进程并发冲突处理。

## 回归证据

新增三项真实文件系统回归：

1. 导航设置变化后，带未知扩展字段及自定义排版的历史文件字节、修改时间、解码内容保持不变。
2. 更新一条记录、添加新记录后可正确回读，另一条历史文件字节及修改时间不变。
3. 既有历史损坏时保存失败，损坏文件及平台配置原始字节均保留。
