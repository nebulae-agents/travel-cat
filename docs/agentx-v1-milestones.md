# AgentX v1 范围与阶段验收

更新：2026-11-19（本次补充 M0 验证状态，其余阶段沿用 2026-11-15 计划）。依据项目现有试点、build58 架构说明，以及本地 v1.6 设计对照报告。本文是交付计划和门禁，不代表各阶段已实现；负责人和日期尚未确定。

v1 主线：agentxd、桌面壳、CLI、Pi 适配器、舞台 / 看板骨架与 v3 皮肤。v1 验收前暂停向 native-http、外部探测和其他非 v1 执行路径扩展新功能；保留既有功能，必要缺陷、安全和兼容修复继续允许。未经单独验收，不迁移或清理正式数据，不宣称服务已经接管全部桌面写入。

## 阶段表

| 阶段 / 对应反馈 | 目标与主要位置 | 依赖与退出条件 | 验证与状态 |
| --- | --- | --- | --- |
| M0 审计闭环 / OPT-02a、05 | `Runtime/agentxd*.py`、`AgentXAuditHelper.swift`、`AgentAuditStore.swift`、`Scripts/agentx` | 服务创建、取消请求、终态通过 Swift 加密桥写入现有审计格式；待写事件可恢复；开始失败不执行，取消不等待审计才发信号；按 run 查询并校验链 | 本地实现、自动回归及真实 Keychain / 原生客户端 / CLI 隔离闭环已于 2026-11-19 通过；新版整包安装仍待验收，见审计文档 |
| M1 写入所有权 / OPT-01、14 | `AgentXController.swift`、`AgentXPilotClient.swift`、服务 API 与 Repository | 按对象逐级移交配置、实例和运行写入；任一级只允许一个权威写者；历史只读与回退边界清楚 | 双客户端并发、旧快照不覆盖、服务中断恢复、正式数据前后清单；待实施，DRI/日期待确认 |

| M4 统一事件与强制权限 / OPT-02b、06 | 拟增应用事件存储、投影重建、运行权限实施 | 运行/徽标可从事件重建；明确保留、游标和升级策略；应用权限在真实执行边界生效 | 删除隔离副本的投影可重建；越权文件和网络访问失败；不把当前 64 条窗口当完整事件源；待实施 |
| M5 应用能力 / OPT-08、09、10、11 | 记忆读写、统一发布号、评估门禁、平台审批 | 记忆分支格式先定稿；一次发布有单一可回滚版本；审批绑定动作摘要、期限和单次消费；依赖工具适配器、事件和权限 | 分支祖先读取、回滚、评估阻断、过期/重复审批拒绝；待实施 |
| M6 v1 前台与交付 / OPT-12、13 | 壳、舞台 / 看板、皮肤、服务打包与生命周期 | 对设计画板逐屏核对；服务与桌面版本匹配；常驻化、崩溃恢复、规模基准明确 | 原生客户端完成创建→执行→停止→审计→重启回读；1,000 条历史基准；安装包身份与正式数据保护；待实施 |

各阶段由实际修改文件、测试证据、客户端验收记录及已知缺口共同关账。开发完成、自动测试通过、客户端验收、安装和远端发布分别记录。新增阶段需求应先说明依赖及验收，不以增加页面数量替代运行闭环。

## 每阶段验收清单

- [ ] 明确本阶段 DRI、检查点和完成日期；未知项保留待确认。
- [ ] 固定基线提交和未提交差异，保留源报告及既有改动。
- [ ] 用隔离 root 覆盖正常、错误、重复请求、并发、服务中断和重启恢复。
- [ ] 没有上游凭据、提示词、回复或异常原文进入审计元数据。
- [ ] 原生客户端与 CLI 的同一对象 ID、修订和状态一致；无法验收时明确缺口。
- [ ] 如启动真实客户端，正式数据在前后扫描中保持一致；仅凭临时目录测试不作此声明。
- [ ] 提交前运行上传审计；安装与远端发布仅按明确授权进行。
