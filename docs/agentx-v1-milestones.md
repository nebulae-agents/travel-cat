## 2026-11-22 M1 首段双应用验收

本次以合并后的 `main`（`67e57ef`）为基线，在隔离数据根登记两个测试应用。一个 `agentxd` 实例独占根锁，按应用分别处理运行记录、执行和审计。桌面与 CLI 走同一套运行 API。旧单应用配置仍受支持。桌面沿用同一数据根内运行 ID 唯一的要求。[配置说明](agentxd-p0-1-pi-pilot.md#m1-首段的多应用配置)

- **服务与 CLI**。同名运行 ID 按应用分别读写，两边的事件和审计各自归属。受控 Pi 测试子进程分别走完停止与自然结束，服务重启后回读到原终态。[多应用回归](../Tests/AgentRuntimeTests/test_agentxd_multi_app.py) · [API 契约回归](../Tests/AgentRuntimeTests/test_agentxd_api_contract.py)
- **桌面**。Swift 控制器连接实际运行的本机 `agentxd`，在两个应用之间切换、标记已读并撤销。旧修订号产生冲突时可读回新版本。保存旧快照和服务断开时，两套运行文件均未被桌面改写。[桌面回归](../Tests/TravelCatAppTests/AgentXPilotOwnershipTests.swift)
- **自动化结果**。Runtime 288 项、CLI 3 项通过。XCTest 共 1,948 项，19 项按条件跳过，0 项失败。Swift Testing 88 项通过。
- **正式数据核对**。前后比对 7 处受保护路径（含 2 处前后均不存在的路径），共 10,423 个条目。正式 `TravelPetData` 的清单完全一致。其余路径的文件内容和条目也一致，仅 `AgentXManager` 的 `automatic-travel.json` 及其父目录修改时间变化。

本次结果覆盖隔离环境和自动化桌面联调。人工操作原生窗口、真实模型及新版正式安装仍待单独验收。M1 的后续移交保持待实施。
