# 外部运行器只读实时探测验收

日期：2026-11-09。范围：用户确认设计后的工作树实现与相关验收；不安装、提交或推送。正式客户端仍为 1.6.0/build57。

## 实现结果

- 详情页保留本机观测与历史停止记录，增加独立外部探测卡片。打开立即刷新，此后每 5 秒刷新；手动刷新合并为同一在途请求；关闭停止调度。
- 每轮显示开始/完成时间、逐目标最近成功时间、明确覆盖范围与固定脱敏失败原因。超过 15 秒标记过期；失败成为当前结论，旧成功仅以历史时间保留。
- 原生 Codex 仅读取已有连接任务的一页后台终端列表，表示该只读接口有响应，不证明模型或认证可用。不启动服务、不恢复会话、不发起推理。
- Docker 仅 inspect 本次运行器创建并登记的不可变容器 ID，使用原上下文/主机并核对 ID/name。不扫描容器、不退回默认上下文。旧对象无可验证 ID 时明确未探测。
- 旅行 CLI/Pi 只核对当前宿主登记的进程身份。Pi 采用内存回执，不扫描旧会话磁盘账本；历史 run 仅用于应用归属过滤，不要求历史记录全部存在当前缓存。进程存活不代表服务可用。
- 协调器同时绑定宿主代次、连接代次及请求序号。正常完成与超时均拒绝旧代次；快速关闭重开的会话令牌阻止旧界面清除新结果。观测不写停止记录、业务任务状态或持久化格式。

## 边界与预算

界面及现有 Swift 传输上限 3 秒。Python 读取预算 2.2 秒，总分派/投递预算 2.5 秒；最多读取 8 个对象。锁忙立即返回未探测/忙碌，各层始终有覆盖项。

观察请求采用小帧非阻塞发送；Python 回复使用非阻塞原子写入，服从真实 macOS 512 字节 PIPE_BUF。结果 ID 稳定脱敏，覆盖说明由客户端固定映射；超过原子帧容量时按层显示覆盖不足，不把截断结果当成完整覆盖。输出背压时丢弃当轮完整回复，客户端显示超时，不留下半条 JSON。

原生 WebSocket 小读取帧若部分写入后超时，未发送尾部只保留在该连接内存中；后续发送在同一写锁下先补齐尾部，防止破坏正常消息。没有后台续写、重连或关闭引擎；迟到读取响应被忽略，界面保持原超时结论。此路径由连续部分发送回归验证。

旅行/Pi 的覆盖为有限登记集合，达到数量上限、缺少身份或锁忙时明确未知/未探测，不宣称全系统退出。
