# 自定义角色

角色导入、按旅程固定角色、命令行与设置选择、真实测试的角色传递已实现并通过自动测试；插件和完整发行包仍在开发与验收中。当前已安装应用尚未包含这些改动。本文不是已完成安装的说明，不需要手动编辑应用内部文件。

## 支持的素材

首版接入已有的 Codex v2 宠物文件夹，其中包含 `pet.json` 和透明 WebP 动画图集。图集尺寸为 1536 × 2288。默认黑猫使用项目中已有的原始素材，不重新生成或压缩。

已有四字段清单可直接识别：

```json
{
  "displayName": "我的宠物",
  "description": "描述外观、颜色与气质。",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

还可提供可选 `id` 和 `referenceImagePaths`。没有 `id` 时使用来源文件夹名；稳定 ID 最长 64 个字符，只接受小写英文字母、数字和连字符。名字最长 128 个字符，描述最长 4096 个字符。不识别的清单字段会报错。

参考图最多三张，格式为 PNG 或 WebP，每边不超过 4096 像素。所有素材路径必须相对于该文件夹，不能通过绝对路径、上级目录或符号链接引用外部文件。清单最大 64 KiB，单张素材最大 16 MiB，导入素材总量最大 48 MiB。

没有参考图的合法动画宠物仍可导入，但不能据此保证生成明信片中的角色一致，也不能拿默认黑猫参考图代替它。

真实测试每次开始时读取新选择，并将该角色复制到独立测试区域。中途改选不会改变正在进行的测试，下一次测试才使用新选择。没有参考图时，设置会提示外观一致性限制。紧凑测试始终是内置黑猫演示，不表示自定义宠物的实际生成效果。自动验证使用模拟生成器，尚未进行真实额度调用和图片效果验收。

## 保留原文件

导入后使用应用数据目录中经过验证的独立副本，原宠物文件夹不变。再次导入相同内容复用同一版本；修改素材后重新导入会产生新版本。失败时保留此前选择，损坏的版本明确报错。

不要手动编辑副本、选择指针或历史旅行中的角色记录。它们共同保持同一角色版本的可追溯性。

应用的数据导出和清除历史前备份会保留角色选择、旅程角色及其素材版本，包括旧旅程使用过的版本。此能力已通过临时样本测试；源码及应用发行包仍不会包含任何个人旅行数据。

## 两个不同的选择

旅行角色决定旅程内容和明信片中的角色。Codex 桌面上显示哪个宠物则由 Codex 自身管理。导入旅行角色不代表已经切换了 Codex 原生宠物，也不会覆盖用户已有的同名宠物。

存储层已经验证：一次旅程开始后固定角色；中途改选只影响下一趟旅程；旧明信片补图仍使用原旅程角色。界面会分别展示“当前显示”和“已选择”，避免将下一趟的选择误认为当前旅程已经换了角色。真实生成与插件链路完成验收前，不能仅因导入成功就认定已经全部生效。

## 描述不是指令

名称、描述和图片文字只用于角色表达。不要在其中放账户信息或秘密；生成时它们可能发送给服务。任何要求执行命令、读取无关文件或修改授权的文字都不应被执行。更多边界见[安全说明](security.md)。
