Travel Cat 1.2 — 安装与开始旅行

适用：macOS 14 或更新版本。本安装包对应构建机器架构，文件名标明 arm64（Apple 芯片）或 x86_64（Intel）。

1. 解压后保持文件在同一目录，双击 Install.command。
   安装到 ~/Applications/Travel Cat.app 并打开。升级会备份旧应用、保留旧相册位置，不移动或清空历史。
   第一次安装也可将 Travel Cat.app 放入“应用程序”后打开；旧版本升级请使用安装器，以保留旧版数据位置。
2. 首次启动显示“模型与连接”，分别选择文字服务和图片服务。
   OpenAI 兼容：填写完整服务根地址（通常以 /v1 结尾）、可用模型名和 API Key。
   本机 Ollama：先自行启动 Ollama 并准备模型，点击本机预设，填写本机已安装的模型名。
   Ollama 文字服务并不意味着支持照片，请另外选择支持图片生成的服务。
   Codex 可选：需在本机已安装并登录 Codex CLI，照片需要账号支持图片生成。
3. 点击“测试文字连接”和“试生成照片”。照片试生成可能计费，只作预览，不加入相册。
   支持图片编辑的服务可使用三张角色参考图；关闭参考图后角色一致性可能下降。
   图片服务必须返回 PNG、横向 3:2、至少 1152×768；应用请求尺寸为 1536×1024。
4. 点击“保存并完成配置”。菜单栏“设置”中可控制自动旅行、安静时段和登录启动。
   自动旅行需应用运行，电脑睡眠时暂停；唤醒后接续。新装未配置不会自动请求模型。
   API Key 保存在本机系统钥匙串，服务设置与历史相册分开保存。

新安装数据：~/Library/Application Support/TravelCat/TravelPetData
升级安装保留旧位置，位置记录在同级 data-location.json；不要删除旧相册目录。

本包仅有本地 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证。
如果 macOS 阻止打开，请遵循系统“隐私与安全性”的提示，仅允许你确认来源可信的应用。
无需关闭系统安全功能。正式面向其他用户分发前仍需 Developer ID 签名和公证。

兼容性：支持 chat/completions 和 images/edits 或 images/generations 的服务；
并非所有宣称“OpenAI 兼容”的服务都支持图片、JSON 模式或同样的尺寸。
Claude/Gemini 的原生接口当前没有内置适配；可使用服务方提供的兼容接口，须自行测试。
任何配置或重装都不应通过清空历史相册来解决问题。
