# 独立应用示例

`writing-room/` 是可导入的声明式应用包，未自动安装，无演示业务记录或凭据。
更新 `payload/frontend.json` 与 manifest 的 version 即可发布自己的界面版本，无需重编译宿主。
在管理窗口登记导入后正常退出并重启，为应用创建自己的定义、模型引用和实例，再从前台填写表单。
按钮先展示发送预览，只有用户点击后才调用所选实例；应用不能提供宿主可执行代码。

SDK 的 `AppFrontendContract` 可独立解析与验证，v1 仅支持 form 模块，字段和模板变量严格校验。
输入保存在各自 `apps/<id>/state/frontend-values.json`；升级 payload 不覆盖输入。
没有前台声明的旧应用继续使用原生聊天界面；损坏声明阻止加载，不静默降级执行。
其他运行框架仍需单独的沙箱执行器，声明式界面不代表运行框架已接入。
